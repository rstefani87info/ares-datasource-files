# Context @datasource-files

Cartella di contesto applicativo del modulo.

Questa directory raccoglie documenti .md di contesto prodotti per l'applicazione/modulo: scopo, architettura, flusso runtime, decisioni, mappatura con gli altri moduli. Nessun file qui è codice eseguibile.

> I documenti di ./context/ vengono passati come riferimento all'AI nelle operazioni di analisi del progetto runtime (vedi comandi project:* di @ares/scd).

## Convenzione

- File .md in lingua richiesta (--lang=it|en).
- Un documento opzionale index.md che elenca i documenti di contesto disponibili.
